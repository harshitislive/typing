    CSV format

    The first row is a header. Only text is required. Put text that contains commas inside double quotes.

    title,category,text
Office basics,Class 1,"Type this line carefully, then check your accuracy."
Capital letters,Class 1,Ravi Priya Aman Neha Sita Gita
Daily practice,Class 2,Short practice every day beats long practice once a week.

    Columns can be named title, category and text. Without a header, two columns are read as title and text, and three columns as title, category and text. Fancy quotes and dashes are changed to plain ones so they can be typed on any keyboard.
